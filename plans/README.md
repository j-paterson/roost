## Findings considered and rejected

(So nobody re-audits these.)

- CORRECTNESS-04 (resync double-count): by design — display subtracts
  `resynced` from `skipped` (`vault-writer.ts:241,282`). Pinned by plan 006.
- CORRECTNESS-06 (unchecked `pages[0]`): already guarded (`?.` + `?? 1` +
  explicit bounds check at `vault-writer.ts:594-602`).
- CORRECTNESS-07 (stale retry log): mischaracterized; `r` is reassigned before
  `onProgress` (`article-fetcher.ts:466-473`).
- CORRECTNESS-08 (sync fs in onProgress): intentional per-item durability
  design (comment at `article-backfill.ts:206-211`); small JSON writes, no
  measurable freeze.
- CORRECTNESS-09 (timeout on `vault.modify`): abandoning a vault write can't
  cancel it and masks real failures; a hung `vault.modify` means Obsidian
  itself is broken.
- CORRECTNESS-10 (`as any` in scanIncompleteIds): cast exists but runtime
  guards make the claimed impact unsubstantiated.
- CORRECTNESS-11 (deletedIdsCache "never cleared"): tombstones are persisted
  by design; restart wouldn't change behavior either. Real (different) gap:
  no un-tombstone path for deliberately re-bookmarked items — file under
  product backlog, not a bug.
- CORRECTNESS-12 (silent media failures): failures return null and are
  handled; frontmatter doesn't get broken refs.
- SECURITY-03 (innerHTML SVG logo): guarded lookup from a hardcoded
  `PLATFORM_LOGOS` map; no user data reaches it.
- SECURITY-04 (plaintext API key in data.json): platform-standard Obsidian
  plugin storage, documented in-code; not actionable at the plugin level.
- SECURITY-08 (sanitizeFilename path traversal): the regex strips `/`, `\`,
  and `:` (`extract.ts:425`), so traversal sequences can't survive; ".."
  without separators is inert in vault paths.
- SECURITY-09 (sidecar `--host` override): explicit user opt-in flag with a
  safe loopback default — by-design CLI configurability.
- SECURITY-11 (PII in errors): record ids aren't PII; LLM error text is
  caught upstream.
- PERF-01 (centroid dedup O(n²)): merged-item skip exists (line 76); n is
  small.

  `Promise.all`.
